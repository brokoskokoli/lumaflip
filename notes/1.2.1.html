A new icon, reviewed translations in all 18 languages and an offer to become the default app. Windows builds are now code-signed and update themselves.

Added

  • Windows: automatic updates with WinSparkle — "Check for Updates…" and the automatic daily check as on macOS, EdDSA-signed installers from a separate feed; the installer updates in place and restarts Lumaflip. [F-MAC-08]
  • Windows: signed releases — installer, ZIP, Lumaflip.exe, the decoder helper and WinSparkle.dll are code-signed (Azure Artifact Signing) and timestamped.
  • Offer to become the default app: opening an image of a type another app opens by default shows an info bar at the top of the window ("Set", "All Image Formats…", "Don't Ask Again", close) – once per type, only in the installed app, never in full screen or a slideshow; can be turned off in Settings → General. [F-MAC-09]

Changed

  • German UI texts follow the macOS German terminology and one term per concept (translations/GLOSSARY.md): "Sichern" for save, "Widerrufen" for undo, "Benutzte Dokumente", "Markieren/Ablehnen" for pick/reject, "App" instead of "Programm", consistent "du". Existing translations were kept (tools/i18n_rename_source.py). [F-I18N-01]
  • All 17 translations reviewed against the terms macOS, Windows and Lightroom use in each language (menu names, standard commands, punctuation and form of address as on the platform); every language is fully translated. Native-speaker reviews are still welcome (translations/REVIEW_STATUS.md). [F-I18N-01]
  • New app icon "Sun Chevron": a forward arrow with the sun in its opening, on teal; the website uses the matching colours.

Fixed

  • A language switch now reaches every window, also one whose native window Qt re-created at that moment (some texts stayed in the old language). [F-I18N-03]
  • Update notes no longer show the line breaks of the changelog source.
