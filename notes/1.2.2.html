Arrow buttons on the image, and Windows now follows the Explorer window's sort order.

Added

  • Previous/next arrow buttons on the image: round, semi-transparent buttons at the left and right edge fade in when the mouse moves and out after 1.5 s without a move, like the title strip. A click flips like ←/→ (wrap, archives, right-to-left comics); no button where there is nothing to go to, none in the grid, compare, crop, slideshow or with the loupe. Settings → Display → "Show arrow buttons at the image edges" (on by default). [F-NAV-09]
  • Windows: images in the order of the Explorer window — opening an image from Explorer takes over the sort column and direction (and grouping where possible) of the Explorer window showing its folder; on by default, can be turned off in Settings → Navigation. [F-SORT-04]

Fixed

  • Windows and Linux: the sort status named the Finder — it now says "Explorer" on Windows ("As in Explorer: …", "Name ↑ (Explorer view not found)") and "file manager" on Linux, as do the menu item and the settings. [F-SORT-05]
  • Windows and Linux: "Show in Finder" — the File menu command, the button on the error card and the shortcut list now say "Show in File Explorer" on Windows and "Show in File Manager" on Linux; the "When opening from …" setting and the missing-permissions hint name the platform's file manager, too. [F-FILE-02]
  • Windows installer shows the Lumaflip icon in the setup wizard instead of Inno Setup's default pictures, and names "Stefan Richter" as publisher, matching the code signature.
